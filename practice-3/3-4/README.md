# Практика 3-4. Диагностика сетевых соединений

Был запущен TCP-сервер на порту 8081.

С помощью команды `lsof -i :8081` был найден процесс сервера:

COMMAND   PID USER   FD   TYPE DEVICE SIZE/OFF NODE NAME
server  27739 user    3u  IPv4 481272      0t0  TCP *:tproxy (LISTEN)

- PID процесса: 27739
- TCP-сокет: *:tproxy
- состояние сокета: LISTEN

Это означает, что сервер успешно прослушивает TCP-порт и ожидает подключения клиентов.

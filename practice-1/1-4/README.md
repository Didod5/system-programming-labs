# Задание 1-4: Диагностика процессов

## Описание задания

Цель задания — изучить диагностику процессов в Linux с использованием
стандартных системных утилит.

Необходимо:

1. Запустить процесс в фоне
2. Найти его PID
3. Проверить загрузку CPU
4. Завершить процесс с помощью сигнала
5. Убедиться, что процесс завершён

---

## Требования

- Использовать утилиты:
  - `ps`
  - `top`
  - `lsof`
  - `/proc`
  - `kill`
- Сохранить используемые команды и результаты

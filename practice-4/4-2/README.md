# Практика 4-2. Отображение файла в память через mmap()

## Описание

Программа создаёт файл и отображает его в память с помощью `mmap()`.

Строка записывается напрямую через отображённую область памяти.

Используются системные вызовы:
- open()
- fstat()
- mmap()
- munmap()
- close()

## Компиляция

```bash
gcc -Wall -Wextra -o task task.c

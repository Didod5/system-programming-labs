# Задание 1-3: Файловая система и права доступа

## Описание задания

Необходимо написать bash-скрипт, демонстрирующий работу с файловой системой Linux,
жёсткими и символическими ссылками, а также правами доступа.

Скрипт должен:

1. Создать файл `data.txt`
2. Создать жёсткую ссылку `hardlink.txt`
3. Создать символическую ссылку `symlink.txt`
4. Удалить файл `data.txt`
5. Проверить, какие ссылки продолжают работать после удаления исходного файла

---

## Требования

- Использовать **bash-скрипт**
- Использовать работу с правами доступа (`chmod`)
- Запуск скрипта:
  ```bash
  chmod +x script.sh
  ./script.sh

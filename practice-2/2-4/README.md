# Задание 2-4: Отладка с использованием strace

## Описание задания

Цель задания — изучить работу системных вызовов в Linux с помощью утилиты `strace`.

Необходимо:

1. Запустить команду `ls -la` под управлением `strace`
2. Сохранить трассировку системных вызовов
3. Найти все вызовы `openat()`
4. Подсчитать количество открытых файлов
5. Сохранить команды и результаты анализа

---

## Требования

- Использовать утилиту `strace`
- Сохранить вывод трассировки в файл `ls_trace.txt`
- Сохранить анализ и команды в файл `analysis.txt`

---

## Ход выполнения

### 1. Запуск strace

Команда для запуска трассировки системных вызовов:

```bash
strace -o ls_trace.txt ls -la

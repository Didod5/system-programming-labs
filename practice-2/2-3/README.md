# Задание 2-3: Обработка сигналов

## Описание задания

Необходимо написать программу на языке C, демонстрирующую обработку сигналов
в Linux.

Программа должна:

1. Создать файл `pidfile.txt` и записать в него PID процесса
2. Работать в бесконечном цикле
3. Корректно обрабатывать сигнал `SIGTERM`
4. При получении `SIGTERM`:
   - закрыть файл
   - удалить файл `pidfile.txt`
   - завершить работу программы

---

## Требования

- Использовать `signal()` или `sigaction()`
- Обработчик сигнала должен быть **async-signal-safe**
  - использовать `write()` вместо `printf()`
- Использовать флаг типа `volatile sig_atomic_t`
- Компиляция:
  ```bash
  gcc -Wall -Wextra -o task task.c

# Практика 4-1. Динамическая память

## Описание

Программа создаёт динамический массив из 10 элементов с помощью `malloc()`,
после чего увеличивает его размер до 20 элементов с использованием `realloc()`.

Используются функции:

- malloc()
- realloc()
- free()

```bash
gcc -Wall -Wextra -o task task.c

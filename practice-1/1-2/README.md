# Задание 1-2: Процессы fork / exec

## Описание задания

Необходимо написать программу на языке C, демонстрирующую работу с процессами
в операционной системе Linux с использованием системных вызовов.

Программа должна:

1. Создать дочерний процесс с помощью `fork()`
2. В дочернем процессе:
   - вывести PID процесса и PID родителя
   - вычислить сумму чисел от 1 до 1000
   - вывести результат
3. В родительском процессе:
   - дождаться завершения дочернего процесса с помощью `wait()`
   - вывести PID родительского и дочернего процессов
   - вычислить произведение чисел от 1 до 10
   - вывести результат
4. Использовать `exec()` для замены образа дочернего процесса
5. Обрабатывать ошибки системных вызовов

---

## Требования

- Использовать системные вызовы:
  - `fork()`
  - `exec()`
  - `wait()`
  - `getpid()`
  - `getppid()`
- Обрабатывать ошибки с помощью `perror()`
- Компиляция:
  ```bash
  gcc -Wall -Wextra -o task task.c
- Запуск:
```bash
  ./task

# Задание 2-1: Многопоточность (pthread)

## Описание задания

Необходимо написать программу на языке C с использованием библиотеки `pthread`,
демонстрирующую работу с потоками.

Программа должна:

1. Создать три текстовых файла:
   - `file1.txt`
   - `file2.txt`
   - `file3.txt`
2. Создать **три потока**
3. Каждый поток читает **свой файл** и подсчитывает количество символов
4. Главный поток ожидает завершения всех потоков и выводит **общее количество символов**

---

## Требования

- Использовать библиотеку **pthread**
- Использовать функции:
  - `pthread_create()`
  - `pthread_join()`
  - `pthread_exit()`
- Компиляция:
  ```bash
  gcc -pthread -o task task.c

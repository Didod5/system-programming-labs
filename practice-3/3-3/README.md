# Практика 3-3 — TCP клиент и сервер

## Описание

Реализовано взаимодействие TCP-клиента и TCP-сервера.

Сервер ожидает подключение клиента,
принимает сообщение и выводит его на экран.

Клиент подключается к серверу
и отправляет текстовое сообщение.

Используются:

- `socket()`
- `bind()`
- `listen()`
- `accept()`
- `connect()`
- `send()`
- `recv()`
- `close()`

---

## Компиляция

```bash
gcc -Wall -Wextra -o server server.c
gcc -Wall -Wextra -o client client.c
```

---

## Запуск

Сначала сервер:

```bash
./server
```

Затем клиент:

```bash
./client
```

# Лабораторная работа: Работа с файлами с использованием системных вызовов

## Описание задания

Необходимо написать программу на языке C, которая:

1. Создаёт файл `input.txt`
2. Записывает в него **50 случайных целых чисел**, разделённых пробелами
3. Считывает числа из файла `input.txt`
4. Находит **максимальное число**
5. Записывает найденный максимум в файл `max.txt`

При реализации **запрещено** использовать стандартные функции файлового ввода-вывода.

---

## Требования

- Использовать **только системные вызовы**:
  - `open()`
  - `read()`
  - `write()`
  - `close()`
- **Запрещено** использовать:
  - `fopen()`
  - `fprintf()`
  - `fscanf()`
- Обрабатывать ошибки с помощью `perror()`
- Компиляция:
  ```bash
  gcc -Wall -Wextra -o task task.c

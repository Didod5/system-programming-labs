# Задание 2-2: Синхронизация с мьютексами

## Описание задания

Необходимо написать программу на языке C с использованием библиотеки `pthread`,
демонстрирующую синхронизацию потоков с помощью мьютексов.

Программа должна:

1. Иметь глобальную переменную `balance`, инициализированную значением `1000`
2. Создать три потока
3. Каждый поток выполняет 100 операций увеличения `balance` на 10
4. Использовать мьютекс для защиты общей переменной
5. В результате значение `balance` должно быть равно `4000`

---

## Требования

- Использовать тип `pthread_mutex_t`
- Использовать функции:
  - `pthread_mutex_init()`
  - `pthread_mutex_lock()`
  - `pthread_mutex_unlock()`
  - `pthread_mutex_destroy()`
- Компиляция:
  ```bash
  gcc -pthread -o task task.c

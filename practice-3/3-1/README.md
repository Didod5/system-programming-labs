# Практика 3-1 — Неименованные каналы pipe()

## Описание

Программа создаёт неименованный канал с помощью `pipe()` и порождает
дочерний процесс через `fork()`.

Дочерний процесс читает содержимое файла `input.txt`
и передаёт данные родительскому процессу через канал.

Родительский процесс получает данные из канала
и подсчитывает количество строк в файле.

Используются:

- `pipe()`
- `fork()`
- `read()`
- `write()`
- `close()`
- `wait()`

---

## Компиляция

```bash
gcc -Wall -Wextra -o task task.c
```

---

## Запуск

```bash
./task
```

# Практика 4-3 — Демон и фоновые процессы

## Описание

Программа создаёт демон-процесс, который каждые 10 секунд проверяет
наличие файла `config.txt` и записывает результат проверки в лог-файл.

Используются:

- `fork()`
- `setsid()`
- `chdir()`
- `umask()`
- `close()`

Также реализована обработка сигналов завершения.

gcc -Wall -Wextra -o task task.c
